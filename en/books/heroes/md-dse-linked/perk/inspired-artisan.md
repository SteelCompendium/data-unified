When you make a [project roll](../rule/downtime/project-roll.md) using a skill from the [crafting skill group](../skill/group/crafting.md), you can spend a [hero token](../rule/resource/hero-token.md) to make another [project roll](../rule/downtime/project-roll.md) for the same project as part of the same [respite](../rule/resource/respite.md) activity. You can't use this perk more than once per [respite](../rule/resource/respite.md).
