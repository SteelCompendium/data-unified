When you make a [project roll](scc.v1:mcdm.heroes.v1/rule.downtime/project-roll) using a skill from the [crafting skill group](scc.v1:mcdm.heroes.v1/skill.group/crafting), you can spend a [hero token](scc.v1:mcdm.heroes.v1/rule.resource/hero-token) to make another [project roll](scc.v1:mcdm.heroes.v1/rule.downtime/project-roll) for the same project as part of the same [respite](scc.v1:mcdm.heroes.v1/rule.resource/respite) activity. You can't use this perk more than once per [respite](scc.v1:mcdm.heroes.v1/rule.resource/respite).
