effects:
    - effect: A creature can take the [Ride](ride.md) move action only while mounted on another creature (see [Mounted Combat](../../../rule/combat/mounted-combat.md) below). Alternatively, a creature can use the [Ride](ride.md) move action to have their mount use the [Disengage](disengage.md) move action as a free [triggered action](../../../rule/combat/triggered-action.md). A creature can use the [Ride](ride.md) move action only once per round. A mounted creature can only have this move action applied to them once per round. This movement can be broken up with the rider's maneuver and main action however they wish.
